# Elkifah Ultimate Menu Manager (v4.0)

## Overview
**Elkifah Ultimate Menu Manager** is a powerful, all-in-one WordPress plugin designed to supercharge the way you manage and create navigation menus. Version 4.0 perfectly combines two essential features into a single, seamless plugin:
1. **Ultimate Menu Manager**: A centralized interface for converting and editing menu item targets (Custom Links, Categories, Pages) on the fly, without needing to navigate through the default WordPress "Appearance > Menus" screen.
2. **Auto Page & Menu Generator**: Automatically generate a complete hierarchy of pages and a corresponding navigation menu just by pasting an ASCII tree diagram (e.g., `├──`, `└──`).

## Key Features

### 1. Ultimate Menu Manager
- **Centralized Management**: Manage all your menu items from a single, streamlined dashboard.
- **On-the-Fly Conversion**: Easily convert existing menu items into Custom Links, Categories, or Pages.
- **Live Text & URL Editing**: Update menu titles (anchor text) and URLs directly within the manager table.
- **Smart Recommendations**: Recommends reverting a menu item to a Page if its URL matches an existing Page permalink.
- **Hierarchy Awareness**: Visual representation of menu hierarchy (parent/child relationships) for better navigation context.

### 2. Auto Page & Menu Generator (New in v4.0)
- **Text-to-Pages**: Paste an ASCII tree representation of your desired site structure, and the plugin will automatically create published Pages maintaining the parent-child hierarchy.
- **Instant Navigation**: Simultaneously builds a WordPress Menu ('Navigasi Otomatis Elkifah') with the exact same structure.
- **1-Click Reset**: Easily delete all pages and menus generated by this tool if you need to start over, without affecting other parts of your site.

## Installation & Usage
1. Upload the `elkifah-menu-manager` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the tools via the **Menu Manager** item in the WordPress sidebar:
   - Click **Menu Manager** to edit and convert existing menu items.
   - Click **Auto Generator** (Submenu) to quickly generate new pages and menus from text.
