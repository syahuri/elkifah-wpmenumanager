# Elkifah Ultimate Menu Manager

## Overview
**Elkifah Ultimate Menu Manager** is a powerful WordPress plugin designed to simplify the management of navigation menus. It provides a centralized interface for converting and editing menu item targets (Custom Links and Categories) without needing to navigate through the default WordPress "Appearance > Menus" screen.

## Key Features
- **Centralized Management**: Manage all your menu items from a single, streamlined dashboard.
- **On-the-Fly Conversion**: Easily convert existing menu items into Custom Links or specific Categories.
- **Hierarchy Awareness**: Visual representation of menu hierarchy (parent/child relationships) for better navigation context.
- **Live Text & URL Editing**: Update menu titles (anchor text) and URLs directly within the manager table, including an option to open in a new tab.
- **Menu Selection**: Seamlessly switch between different navigation menus defined in your WordPress site.

## Installation & Usage
1. Upload the `elkifah-menu-manager` file (or folder) to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the tool via the **Menu Manager** item in the sidebar.
4. Select the menu you wish to edit, make your changes, and click **Simpan Perubahan Menu**.
