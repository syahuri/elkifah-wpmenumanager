# Development Log - Elkifah Ultimate Menu Manager

## [3.0] - 2026-04-02
### Added
- Integrated **Dynamic UI Toggle** via JavaScript for enhanced user experience in the manager table.
- Added **Multiple Inputs** for Custom Link conversion (Anchor Text, URL, and Open in New Tab option), allowing full control during the process.
- Added support for **Category Conversion**, allowing users to transform Page/Custom links into Taxonomy items.
- Introduced **Menu Selection Dropdown**, permitting management across multiple navigation sets (Header, Footer, etc.).
- Added visual **Hierarchy Display** with &mdash; indentations for nested menu items.

### Improved
- Optimized the storage logic using WordPress `update_post_meta` and `delete_post_meta` for cleaner data management.
- Refined UI layout with a striped table and better color-coded type labels (Page, Custom Link, Category).

### Changed
- Moved the plugin entry point to its own sidebar menu "Menu Manager" with a dedicated dashicons-admin-links icon.
